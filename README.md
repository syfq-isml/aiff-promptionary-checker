# Guess It!

A small static guessing game designed for GitHub Pages.

## Files

- `index.html` - page structure
- `style.css` - responsive styling and animations
- `script.js` - round navigation, answer checking, unlocking rounds, and confetti

## GitHub Pages

Upload these three files to a GitHub repository and enable GitHub Pages from the repository's Pages settings. No build step or server is required.

## Answer matching

The checker ignores capitalization and punctuation, but preserves spacing. Answers are checked only after the Submit button is pressed.
